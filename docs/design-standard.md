# Стандарт интерфейса Bizdin Auyl

Правила, по которым собран интерфейс. У каждого - причина: правило без причины
со временем «упрощают» обратно.

## Бумага и тушь

- Палитра - бумага (`--bg`, `--surface`) и тушь (`--ink`, `--ink-2`, `--muted`).
  Оттенков у интерфейса нет.
- Цвет означает только две вещи: красный (`--danger`) - отказ, проблема,
  просрочка; зелёный (`--money`) - приход денег. Постоянно горящий зелёный
  «всё хорошо» перестают замечать ровно тогда, когда он должен был напугать.
- Состояние не кодируется цветной точкой или кружком. Его показывает подпись,
  её вес, положение, рамка: «Грязный» на доске хозслужбы весит больше, чем
  «Проверен»; номер к сегодняшнему заезду обведён тушью.
- Обе темы обязательны и проверяются тестами. Ночная тема - не инверсия, а
  свои значения токенов (`tokens.css`).

## Кнопки и выбор

- Кнопки - прямоугольники без скругления. Главное действие - плита
  (`.btn-primary`), остальное - волосяная рамка (`.btn-ghost`), третьестепенное -
  текст (`.btn-quiet`). Пилюль (`border-radius: 999px`) нет.
- Выбранное - весом подписи, рамкой или чертой (`.tab`, `.choice[aria-checked]`),
  а не залитой капсулой.
- На телефоне любая кнопка - не меньше 32 px по высоте: в неё попадают пальцем.

## Текст

- Никаких дежурных надписей: слоганов, описаний «о системе», подписей для
  красоты. Подсказка к полю и объяснение правила («почему нельзя заселить») -
  нужны; теглайн - нет.
- Длинного тире нет нигде: ни в интерфейсе, ни в сообщениях сервера, ни в
  документах. Вместо него - дефис с пробелами: «Касса - смена 12». Пустое
  значение - «-».
- Гость и сотрудник бывают женщиной: статусы и уведомления без рода
  («Проживает», «Выезд оформлен», «Увольнение оформлено»).
- Подпись к числу согласуется с числом (`plural()`): «3 уборки», «5 заявок».
- Деньги - целые тиыны в данных, «12 400 ₸» на экране, цифры табличные в
  столбцах и пропорциональные в крупных числах.

## Окна и движение

- Окна записей (бронь, гость, сотрудник, номер) и диалоги - по центру экрана,
  появляются растворением с небольшим подъёмом; Escape закрывает только верхнее.
- Смена темы - одно растворение всей страницы (View Transitions), без
  поэлементных переходов цвета.
- Вход: небо (WebGL, качество подбирается под устройство, без WebGL - рисунок),
  шаңырақ собирается и распадается на рейки, из них по центру строится окно
  входа. Клавиша или касание сразу ведут к окну. При «меньше движения» в системе
  окно появляется без сборки.
- GSAP - только из `src/components/motion/gsap.ts`. Свойство, которое
  анимирует GSAP, не задаётся в CSS. Рядом с полноэкранными слоями анимируется
  только прозрачность.

## Проверка

- Сквозные тесты (`pnpm e2e`) проходят каждую роль на 1440 / 800 / 390 px в обеих
  темах: нет прокрутки вбок, длинного тире, пилюль, мелких кнопок; доступность
  WCAG 2 AA (axe); окна по центру. Любая ошибка в консоли или ответ 5xx - провал.
- Графики: одна величина - одна ось, тонкие столбцы, подсказка по наведению и с
  клавиатуры, рядом всегда таблица с теми же числами.
